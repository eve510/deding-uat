# Deding UAT Lab

Deding 官網報名系統的上線前驗收工作台，將六位資深員工的 66 個測試案例、18 個改善提案，以及工程師修正追蹤整合在同一個靜態網站。

## 功能

- 員工 A–F 各自執行不重複的桌機、必填防呆、選項組合、手機、破壞性與結帳付款任務包。
- 每案可勾選完成、標示通過／失敗／阻塞，並記錄嚴重度、實際結果與證據。
- 每位資深員工另有體驗評分卡與三題改善提案。
- 所有資料儲存在目前瀏覽器；可匯出 JSON 備份或交給工程師。
- 工程統籌頁可重複匯入六人的 JSON，合併問題與提案，記錄負責人、修正狀態、Commit／PR／版本與 QA 複測結果。

## 本機執行

需求：Node.js 22.13 或更新版本。

```bash
npm ci
npm run dev
```

開啟 `http://localhost:3000/`。正式建置與測試：

```bash
npm test
```

## GitHub Pages

`.github/workflows/deploy-pages.yml` 會在 `main` 分支更新時建立靜態網站並部署至 GitHub Pages。儲存庫 Settings → Pages 的 Source 請選擇 **GitHub Actions**。

## 資料注意事項

本網站沒有後端資料庫，也不會自動同步不同裝置。請只使用虛構測試資料，不要輸入真實個資；員工完成後應下載 JSON 並交由工程統籌匯入。瀏覽器資料若被清除且沒有匯出檔案，將無法復原。
